# Release work still required

This repository delivers a working native beta and reviewable source. A locally signed QA archive can now be built, and both complete campaigns are replayed automatically with earned resources. This does not establish physical-device performance, human campaign pacing, final art approval or App Store readiness. See [current hardening evidence](RELEASE-HARDENING.md).

## Explicit beta limitations

The UI exposes the existing game's systems, including advanced actions, through native activity panels. It does not reproduce every browser presentation convenience: persistent pinned goals, three browser target-preset slots, and a named town editor remain absent. Native plain-browser import starts new evolution history because browser evolution lives under a separate storage key. Map position, zoom and the chosen district are remembered locally on the device; they do not travel inside economy exports. There is no automatic synchronization between browser and native saves.

Campaign pacing, final art approval, advanced activity animation and authored-site placement remain release limitations despite the integrated painted-art pass. This port does not silently reclassify those as finished production content. Existing browser play remains on main until the user separately chooses to merge; no deployment changes or automatic merge are part of this work.
