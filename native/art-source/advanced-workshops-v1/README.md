# Advanced workshop silhouettes

Generated with the built-in ImageGen tool on 5 November 2026. `prompt.txt` preserves the complete prompt; `painted-v2/village.png` was the style reference. `atlas.png` is the untouched transparent generated source.

The 4×3 grid follows the twelve real advanced workshop families: mill, bakery, fishing, olive, boatyard, estate, kitchen, kiln, preserving, weaver, carpenter and sailmaker. `pack-advanced-art.swift` performs grid extraction and proportional sizing only. Packed textures are 384px RGBA; source/output hashes and catalog coverage are verified.

Tier-3 previews use all twelve textures. The map selects the corresponding texture for built tier-3 sites. Kiln/preserving share the original physical site: preserving art is used when it alone reaches tier 3; kiln art represents the site when both are tier 3. No extra production site or changed economic footprint is implied.

These are generated raster assets, subject to the same human consistency and artwork-rights review as the rest of the release candidate.
